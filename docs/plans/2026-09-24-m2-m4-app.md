# Flipbook M2–M4 Implementation Plan

> Written when the app was called Flipbook; it's Annotake since 2026-09-30 ([distribution design §3](2026-09-30-distribution-design.md#3-the-name-annotake)).

> **How to execute:** two sessions, each run long and unattended. Session 4 does Tasks 1–20 and ends at Checkpoint 1. Session 5 does Tasks 21–27 and ends at Checkpoint 2. Work through the tasks in order. For each task:
> 1. Write the listed tests.
> 2. Run them with `make test FILTER=<suite>` and watch them fail.
> 3. Implement until they pass.
> 4. Run the task's **Verify** step: always `make test`, and also `make selftest` when the task says so.
> 5. Commit.
>
> Tasks marked **Glue** wrap macOS APIs that unit tests can't reach. They're verified by building, by the self-test, by UI snapshots, and by the log, and they still get unit tests for whatever pure logic they contain.
>
> **Stop and ask Fayzan only when:**
> - macOS shows a permission prompt the session can't answer, or
> - a test expectation in this plan looks wrong. Say why, and don't change the expectation.
>
> Everything else the session verifies itself, and the two checkpoints are the only planned stops. **Never launch the full app during a session**, because it requests permissions at launch. Use `make selftest` and `make ui-snapshots` instead: both run in modes that request nothing.
>
> Steps use checkbox (`- [ ]`) syntax for tracking. Don't use any superpowers skills to execute this plan.

**Goal:** Build the Flipbook app on top of `FlipbookCore`: recording end to end (M2), captioned frames with the card and filmstrip (M3), and Settings, the picker, first launch, menu, retention and sounds (M4).

**Architecture:**
- Four new libraries: `FlipbookCapture`, `FlipbookInput`, `FlipbookExport`, and `FlipbookApp`.
- A one-file `Flipbook` executable that calls into `FlipbookApp`.
- Frames and input reach the picker only through `LiveSession`, a new time-ordered queue in Core. The replayer runs the same code, so raw sessions replay exactly as they ran live.
- Each library keeps its pure logic unit-tested. A self-test records the app's own scripted window through the real pipeline, so unattended sessions can check the glue.

**Tech Stack:** Swift 6.2 (Command Line Tools 26.3), SwiftPM, Swift Testing, AppKit, SwiftUI, ScreenCaptureKit, CoreGraphics event taps, ApplicationServices (Accessibility), CoreText, ImageIO, ServiceManagement.

**Spec:** read both before starting.
- `docs/spec.md`: what the app does.
- `docs/plans/2026-09-24-m2-m4-design.md`: why, and how the pieces fit. Its section numbers are cited as "design §n".
- For history: `docs/spikes/findings.md` (the M0 measurements) and `docs/plans/2026-09-23-m1-core.md` (how Core was built).

**Global Constraints** (every task inherits these):
- **Core** (`Sources/FlipbookCore`) imports Foundation only. There is no network code anywhere and no AI.
- **Language mode** is Swift 6 in every target.
  - Core's public types are `Sendable`.
  - Platform code may use `@preconcurrency import`, `MainActor.assumeIsolated` in AppKit callbacks, and `final class … : @unchecked Sendable` for objects confined to one queue or thread. Name that queue or thread in a comment on the class.
- **Tests:**
  - `make test` runs everything, and `make test FILTER=<regex>` runs matching suites.
  - Never run plain `swift test`: without Xcode it can't find Swift Testing (M0).
  - New test targets need the Makefile's flags, including `-disable-cross-import-overlays`.
  - A test target's `resources:` must be declared only after the folder exists (M1).
  - App tests use `@testable import FlipbookApp` for the app's internal types.
  - Test targets can't share support files, so each suite that needs a helper gets its own.
- **Privacy:**
  - Typed characters never leave the event-tap callback.
  - A secure text field's value is never read.
  - `~/Library/Logs/Flipbook.log` never contains labels, window titles, or keys.
- **Identity and bundling:**
  - Bundle id `com.fayzanmalik.flipbook`, `LSUIElement`.
  - Always bundled and signed through `scripts/bundle-app.sh`, which strips extended attributes and signs with `Flipbook Local Signing`.
  - Build only on the personal MacBook.
- **Commits:** commit after every task. The message ends with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
- **Numbers.** Define each as a named constant where it's used; never repeat the literal:
  - **`LiveSession`:** tick 0.05 s, slot timeout 0.5 s, stamp bump 1 µs.
  - **Accessibility:** messaging timeout 0.25 s.
  - **Starting a capture:** content query timeout 2 s.
  - **Stream:** 10 fps, queue depth 8, BGRA, sRGB, cursor shown.
  - **Output size:**
    - long edge 1920, or 1568 compact;
    - largest side 2000;
    - the caption strip's maximum height ratio `CaptionLayout.maxHeightRatio` = 0.115 of the width (the tallest strip is at most 0.1121 of the width for any width from 400 to 2000 px).
  - **Cursor box:** −12 to +32 pt around the hotspot, times the cursor-size setting.
  - **Signature:**
    - 8 × 8-pixel cells, 4 × 4 cells per 32 px tile;
    - luma `(77·R + 150·G + 29·B + 128) >> 8`;
    - cell mean `(sum + count/2) / count`.
  - **Captions:**
    - line 1 size = width ÷ 64;
    - line 2 size = 0.85 × line 1;
    - line heights round(1.3 × size);
    - padding round(0.8 × line-1 size);
    - gap round(0.3 × line-1 size);
    - line 1 wraps to at most 3 lines;
    - strip background `#1C1C1E`, line 2 color `#A1A1A6`.
  - **Click markers:** radius width ÷ 80, 3 px `#FF3B30` over a 6 px white halo, badge radius 0.45 × the ring radius.
  - **Gestures:**
    - the tick runs every 50 ms while the key is down, while recording, and for 1 s after a release;
    - the trust watchdog checks every 2 s.
  - **Sessions:** hands-free recordings stop at 300 s and are discarded under 0.5 s.
  - **Cards:**
    - a click moves less than 4 pt;
    - the fade after a drop lasts 5 s;
    - at most 4 are visible;
    - 20 pt corner inset, 10 pt gap.
  - **Captures:**
    - Recent Captures lists 5;
    - export renders 4 frames at a time;
    - retention runs every 24 h;
    - the log is capped at 5 MB, with one rotation.
- **Ordering** (from M1): at equal times, frames go before events. Before an item is processed, every tick strictly earlier than it runs.
- **Label and title text** is normalized by `LabelResolver.normalize` (Task 14) before it reaches Core: whitespace runs become one space, the text is trimmed, and it's capped at 120 characters (119 plus "…").

**Review Focus.** Five things the spec implies that no feature test would naturally exercise. Each one's pinning test is listed in its owning task:
1. **Two displays with different scales, including a display left of or above the main one (negative origin).** Clicks and the cursor box must map with that display's origin and scale. Task 5: `negativeOriginDisplayMaps`, `displayAboveMainMaps`.
2. **Keys a layout can't name, and ⌥ dead keys or input methods while typing.** Composing keystrokes are typing, not shortcuts, and a shortcut on an unnamed key still gets a readable name. Task 12: `optionLetterIsTyping`, `unnamedKeyFallsBackToANSI`.
3. **A save location that's missing or unwritable** (an unplugged disk, a read-only folder). A recording must not start and then fail silently: it says so and records nothing. Task 7: `unwritableSaveLocationThrows`. Task 16: `saveLocationFailureShowsMessage`.
4. **Very long or multi-line titles and labels** (a 300-character Jira title, a label containing newlines). Captions stay inside the strip budget, and each `steps.md` step stays on one line. Task 8: `longCaptionsStayInBudget`. Task 14: `labelsAreNormalized`.
5. **The stream dying mid-recording** (display sleep, lid closed, screen locked). The recording ends and saves what it has instead of hanging in "recording". Task 16: `streamEndSavesWhatWasCaptured`, `handsFreeAutoStopsWithoutFrames`.

### Task 3: `LiveSession`, the raw session writer, and the replayer rebuilt on them (Core)

Design §3.4. This task is the foundation of live picking. Follow the semantics exactly.

**Files:**
- Create: `Sources/FlipbookCore/LiveSession.swift`, `Sources/FlipbookCore/RawSessionWriter.swift`, `Tests/FlipbookCoreTests/LiveSessionTests.swift`, `Tests/FlipbookCoreTests/RawSessionWriterTests.swift`, `Tests/FlipbookCoreTests/Support/SeededRandom.swift`
- Modify:
  - `Sources/FlipbookCore/SessionReplayer.swift`: rebuilt on `LiveSession`. Its public API doesn't change.
  - `Sources/FlipbookCore/RawSession.swift`: `SessionFile` becomes `internal`.

**Interfaces (Produces):**

```swift
public struct LiveSession: Sendable {
    public static let tickInterval: TimeInterval = 0.05
    public static let slotTimeout: TimeInterval = 0.5
    public static let stampBump: TimeInterval = 0.000_001
    public struct Slot: Hashable, Sendable {}                       // opaque
    public enum Output: Sendable, Equatable {
        case persist(frameIndex: Int, reason: KeepReason, at: TimeInterval)
        case discard(frameIndices: [Int], at: TimeInterval)
        case tookFrame(FrameSample)      // the picker ingested it; time = effective stamp
        case tookEvent(InputEvent)       // ditto; a slot's event carries its final kind
    }
    public init(geometry: CaptureGeometry, config: PickerConfig = PickerConfig(), initialContext: FrameContext)
    public mutating func receive(_ frame: FrameSample) -> [Output]
    public mutating func receive(_ event: InputEvent) -> [Output]
    public mutating func reserve(_ placeholder: InputEvent) -> (slot: Slot, outputs: [Output])
    public mutating func fill(_ slot: Slot, with kind: InputEventKind, now: TimeInterval) -> [Output]
    public mutating func advance(to now: TimeInterval) -> [Output]
    public mutating func stop(at time: TimeInterval) -> [Output]
    public var isFinished: Bool { get }
    public var stopTime: TimeInterval? { get }       // the effective stamp of stop, once called
    public var candidateCount: Int { get }           // frames kept so far
    public var logicalTime: TimeInterval { get }     // last tick or item processed; -infinity before any
    public var nextTickTime: TimeInterval { get }    // Double(k) * tickInterval for the next tick not yet run
    public func result() -> PickResult               // precondition: isFinished
}

public final class RawSessionWriter {                // not Sendable: confine it to one queue
    public init(directory: URL, geometry: CaptureGeometry, initialContext: FrameContext) throws  // creates dir; opens tiles.bin
    public func append(_ frame: FrameSample) throws  // streams the signature to tiles.bin; keeps index/time/dirtyRects/cursor
    public func append(_ event: InputEvent)
    public func finish(stopTime: TimeInterval) throws  // writes session.json exactly as RawSessionIO does (version 1)
}
```

**Semantics (load-bearing):**
1. **Stamps.** `receive`, `reserve`, and `stop` each stamp their item with the given time. If that time is ≤ the last stamp, it becomes `last + stampBump`. A bumped frame is rebuilt with its new time. `fill` and `advance` create no item: their `now` is only the horizon.
2. **Queue.** Items wait in one first-in-first-out queue: frame, event, slot (holding its placeholder and, once filled, its final kind), and stop. After every call, drain it up to the horizon `h`: the call's own time, or its `now` argument.
   ```
   loop (while not finished):
     if the queue is empty:  runTicks(through: h); return
     head = queue.first
     if head is an unfilled slot and h − head.time < slotTimeout:  runTicks(before: head.time); return
     runTicks(before: head.time); process(head); remove it
   ```
   - `runTicks(before: t)` runs every tick with `Double(k) * tickInterval < t`.
   - `runTicks(through: h)` runs every tick with `Double(k) * tickInterval <= h`.
   - k starts at 0 and only ever increases. Every tick calls `picker.tick(now:)`.
3. **Processing an item.**
   - A frame emits `.tookFrame`, then the outputs of `picker.ingest(frame)`.
   - An event, or a slot turned into its event (the filled kind, or the placeholder's kind on timeout, at the slot's stamp), emits `.tookEvent`, then the outputs of `picker.ingest(event)`.
   - Stop runs `runTicks(through: its time)`, then `picker.stop(at:)`.
   - Picker outputs map to `.persist` / `.discard`. The time is the tick's time or the item's time. A persist's reason is `picker.keptFrames.last!.reason`, read right after the call that produced it.
   - Once `isFinished`, the remaining items are dropped and nothing more is emitted.
4. **Filling a slot** that has already timed out does nothing.
5. **`SessionReplayer.run`** becomes:
   1. Merge the frames and events by time, with frames first at equal times.
   2. Call `receive` for every item with time ≤ `stopTime`.
   3. Call `stop(at: stopTime)`.
   4. Call `receive` for the items after `stopTime`.
   5. While not finished, call `advance(to: live.nextTickTime)`. Fail with `preconditionFailure` after more than `Int((stopSettleTimeout / tickInterval).rounded(.up)) + 4` calls.

   Its log maps `.persist(i, reason, at)` to `.keep(frameIndex: i, reason:)` at `at`, and `.discard` as it is.

4. `store.commit`.

1. If the removal would leave no frames, throw `.cannotRemoveAllFrames` and change nothing.
2. The new frames are `FrameEditing.removing(frameIndices:from:)`. Removed frames are appended to `manifest.removed`.
3. Move `.raw/frame-<i>.png` to `.raw/removed/`.
4. Re-render every remaining frame with its new number and total, then delete rendered files that are no longer in the set.
5. Rewrite `steps.md` and `capture.json`. `candidateCount` and `duration` stay as they were.

**`label(atHit:)`.** Walk from `hit` up through its parents, at most 8 levels. Stop and return nil at `AXWebArea`, `AXWindow`, or `AXApplication`. At each node:

2. For `AXCell` / `AXRow`: take the first descendant, breadth-first and at most 2 levels deep, whose normalized title or value isn't empty. Never read the value of a secure field. Label it with this node's role description.
3. For an `AXCheckBox` (switches included) with no text: use its `titleElement`'s title or value. Failing that, use the first sibling that's `AXStaticText` with a non-empty value.
4. Otherwise, move to the parent.
