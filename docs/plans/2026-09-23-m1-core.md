# Flipbook M1 Core Implementation Plan

> **How to execute:** work through the tasks in order, test-first. For each task:
> 1. Write the listed tests.
> 2. Run them and watch them fail.
> 3. Implement until they pass.
> 4. Commit.
>
> Steps use checkbox (`- [ ]`) syntax for tracking. Don't use any superpowers skills to execute this plan.

**Goal:** Build `FlipbookCore`, the platform-independent brain of Flipbook. It contains:
- the frame picker, which decides which frames to keep (spec §5),
- the Right ⌘ gesture recognizer (spec §3.1),
- cap fitting (§5.5) and filmstrip removal (§3.4),
- captions and `steps.md` text (§4),
- a raw-session format with a deterministic replayer and a `flipbook-replay` CLI for tuning,
- full tests.

**Architecture:** A SwiftPM library that uses Foundation only. No macOS UI or capture frameworks, so a future Windows port can reuse it or port it against the same tests. The picker never sees pixels; it sees per-tile brightness signatures, dirty rects, the cursor rect, and input events. The M2 plan feeds it real data from ScreenCaptureKit and event taps.

**Tech Stack:** Swift 6.2 (Command Line Tools 26.3), SwiftPM, Swift Testing, Foundation.

**Spec:** `docs/spec.md`. Read §3.1, §3.4, §4.2–4.4, §5, and §8. The companion files are `docs/research-notes.md` and `docs/v2-backlog.md`.

**Prerequisites:**
- **Toolchain.** Command Line Tools 26.3 must be installed, so `swift --version` shows 6.2. See M0 plan Task 1 Step 1.
- **Test framework (M0 result).** Swift Testing works under the Command Line Tools, but only with the CLT framework folder added to the compiler and linker search paths; XCTest isn't in the CLT at all. So tests always run through `make test` (Task 1), never plain `swift test`, which fails with `no such module 'Testing'`. `Package.swift` must keep `platforms: [.macOS(.v15)]`, or the `@Test` macros fail to compile.
- **M0 decisions.** `docs/spikes/findings.md` → Decisions. This plan already includes the two that affect Core: the test command (above) and the hold reveal in the gesture recognizer (Task 10, spec §3.1).

**Global Constraints** (every task inherits these):
- `Sources/FlipbookCore` imports **Foundation only**. Never AppKit, CoreGraphics, ScreenCaptureKit, ApplicationServices, Accelerate, CoreImage, or SwiftUI.
- No AI and no network code anywhere.
- **Running tests:** `make test` runs the whole suite, and `make test FILTER=<regex>` runs matching suites. Every "run" step below uses it.
- Language mode is Swift 6 (the default for tools version 6.0). Every public type is `Sendable`.
- **Privacy:** no type may carry typed text. Keystrokes appear only as *kinds* (`keyTyped(field:)`, `keyReturn`, `keyEscape`, `shortcut("⌘S")`).
- **Default numbers (spec §5).** All of them live in `PickerConfig`, so none are hard-coded elsewhere:
  - Tile change: MAD over a tile's 16 signature values must exceed 3 (on 0–255).
  - Caret: at most 4 × 48 pt; its tiles stay ignored for 2 s.
  - Busy tiles: the window is 1.5 s, the threshold is 60% of frames with at least 5 frames, and a tile is released after 2 s still. Frames that change more than 50% of tiles, or arrive during a scroll, don't count.
  - Motion needs at least 2 tiles.
  - Visual trigger: D ≥ 0.02, or ≥ 0.005 once 10 s have passed since the last keep.
  - Keep: D ≥ 0.005. For click, commit, switch, and typing triggers, one changed tile is enough.
  - Settle: 0.4 s of quiet, measured from the later of the last motion and the trigger. The timeout is 3 s; the stop settle timeout is 1 s.
  - Typing pause is 1.2 s. Scroll end is 0.3 s. Scroll keep threshold is 0.8 viewport.
  - Double-click radius is 5 px.
  - Max frames is 20, clamped to 2–50.
  - Candidate pool: 300, trimmed to 150.
  - Cap-fitting bonuses: click 0.15, commit 0.15, switch 0.30, scroll 0.05. Time-gap weight is 0.05.
- **Gesture defaults (spec §3.1):** hold threshold 0.25 s, double-tap window 0.30 s.
- **Text formats (spec §4):**
  - caption line 1: `3/8 · 0:07 · Clicked button "Save"`
  - caption line 2: `Google Chrome — Dayforce · Timesheets`
  - file name: `03_0m07s.png`
  - the separators are ` · ` (U+00B7) and ` — ` (U+2014), and actions are joined with ` → ` (U+2192)
- **Ordering rule (replayer and test harness):** at the same timestamp, a frame is processed before an event. A tick at time T runs only if T is strictly earlier than the next item's time.
- **Commits.** Commit after every task. The message ends with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

```swift
    public init(columns: Int, rows: Int, tileSize: Int)

    public let outputWidth: Int; public let outputHeight: Int

```

**Behaviors to pin:**
- `CaptureGeometry` builds its grid with `columns = ceil(outputWidth / tileSize)` and `rows = ceil(outputHeight / tileSize)`.
- `tiles(intersecting:)`:
  - returns `[]` for an empty rect or one lying entirely outside the grid,
  - clamps partial overlaps,
  - works out the covered columns as `x / tileSize … (x + width − 1) / tileSize`, and rows the same way.
- `tile(containing:)` returns `nil` for negative or out-of-grid points.

**Text rules for `text(for:)`:**
- **Verb for clicks:** `Right-clicked` when the button is `.right`. Otherwise `Double-clicked` when `clickCount >= 2`. Otherwise `Clicked`.
- **Target of a click.** Given `verb`, `role`, and `label`:
  - Target `nil`, or both role and label empty → `"\(verb) at (\(Int(x.rounded())), \(Int(y.rounded())))"`.
  - Role empty → `\(verb) "\(label)"`.
  - Label empty → `\(verb) \(role)`.
  - Otherwise → `\(verb) \(role) "\(label)"`.
- **Typing:** `Typed in field "\(label)"` when the field label is non-empty, otherwise `Typed`.
- **Keys:** `Pressed Return`, `Pressed Esc`, `Pressed \(shortcut)`.
- **Switch:** `Switched to \(line2(for: context))`.
- **Scroll:** `Scrolled`.

**`summary`:**
- If the frame has actions, join `text(for:)` of each with ` → `.
- Otherwise: `number == 1` → `Start`; else `number == total` → `End`; else `Screen changed`.

**`line2`:** the app name alone if the window is `nil` or empty, otherwise `"\(app) — \(window)"`.

### Task 5: ChangeTracker (what changed, motion, exclusions, D)

**Files:**
- Create: `Sources/FlipbookCore/ChangeTracker.swift`
- Test: `Tests/FlipbookCoreTests/ChangeTrackerTests.swift`

**Interfaces:**
- Consumes: `CaptureGeometry`, `TileGrid`, `FrameSignature`, `FrameSample`, `PixelRect`, `PickerConfig`.
- Produces:

```swift
public struct Difference: Sendable, Equatable {
    public let changedTiles: Int; public let consideredTiles: Int
    public init(changedTiles: Int, consideredTiles: Int)
    public var fraction: Double { get }      // consideredTiles == 0 ? 0 : changed / considered
}
public struct FrameChange: Sendable, Equatable { public let changedTiles: Set<Int>; public let motion: Bool }
public struct ChangeTracker: Sendable {
    public init(geometry: CaptureGeometry, config: PickerConfig)
    public private(set) var busyTiles: Set<Int>
    public private(set) var everBusyTiles: Set<Int>
    public private(set) var caretTiles: Set<Int>
    public private(set) var everCaretTiles: Set<Int>
    public mutating func observe(_ frame: FrameSample, previous: FrameSample?, countTowardBusy: Bool = true) -> FrameChange
    public mutating func advance(to now: TimeInterval)
    public func difference(_ a: FrameSample, _ b: FrameSample) -> Difference          // live exclusions
    public func settledDifference(_ a: FrameSample, _ b: FrameSample) -> Difference   // whole-recording exclusions
}
```

**Algorithm (load-bearing):**

`observe(frame, previous, countTowardBusy)`:
1. `advance(to: frame.time)`. If `previous == nil`, return `FrameChange(changedTiles: [], motion: false)`.
2. **Candidate tiles:** the union of `grid.tiles(intersecting:)` over `frame.dirtyRects`, or every tile if `dirtyRects` is empty. `changed` is the candidates where `frame.signature.differs(from: previous.signature, tile:, threshold: config.tileChangeThreshold)`.
3. **Caret:**
   - A rect is *caret-like* if `width ≤ caretMaxWidthPoints × pixelsPerPoint`, `height ≤ caretMaxHeightPoints × pixelsPerPoint`, and `height > width`.
   - `caretOnly` is the tiles of caret-like rects minus the tiles of the other rects.
   - For each tile in `caretOnly ∩ changed`: set `caretSeenAt[t] = frame.time`, and insert it into `caretTiles` and `everCaretTiles`.
4. **Busy.**
   - For each tile in `changed`: `lastChangeAt[t] = frame.time`.
   - Update the history only if `countTowardBusy` is true **and** `changed.count ≤ busyMaxAreaFraction × grid.count`. In that case:
     - Append `(frame.time, changed)` to `history`.
     - Drop entries with `time < frame.time − busyWindow`.
     - If `history.count ≥ busyMinFrames`, every tile appearing in at least `busyFraction` of the history entries goes into `busyTiles` and `everBusyTiles`.
5. **Motion.**
   - `excluded = busyTiles ∪ caretOnly ∪ tiles(frame.cursor) ∪ tiles(previous.cursor)`.
   - `motion = (changed − excluded).count ≥ motionMinTiles`.
6. Return `FrameChange(changedTiles: changed, motion: motion)`.

`advance(to now)`:
- Remove busy tiles with `now − lastChangeAt[t] ≥ busyRelease`.
- Remove caret tiles with `now − caretSeenAt[t] ≥ caretMemory`.

`difference(a, b)`:
- `excluded = busyTiles ∪ caretTiles ∪ tiles(a.cursor) ∪ tiles(b.cursor)`.
- `considered = grid.count − excluded.count`.
- `changed` = the non-excluded tiles where `a.signature.differs(from: b.signature, tile:, threshold:)`.

`settledDifference`: the same, but using `everBusyTiles ∪ everCaretTiles` in place of the live sets.

### Task 6: CapFitter

**Files:**
- Create: `Sources/FlipbookCore/CapFitter.swift`
- Test: `Tests/FlipbookCoreTests/CapFitterTests.swift`

**Interfaces:**
- Consumes: `KeptFrame`, `FrameSample`, `Difference`, `PickerConfig`, `StepAction`, `KeepReason`, `SceneBuilder.keptStub`.
- Produces:

```swift
public enum CapFitter {
    /// Removes the lowest-cost interior frame until at most max(2, cap) remain.
    /// A removed frame's actions are appended to the previous remaining frame.
    /// Returns the remaining frames in time order, and the removed frame indices in removal order.
    public static func fit(_ frames: [KeptFrame], cap: Int, config: PickerConfig,
                           difference: (FrameSample, FrameSample) -> Difference) -> (kept: [KeptFrame], removed: [Int])
    public static func bonus(for frame: KeptFrame, config: PickerConfig) -> Double
}
```

**Algorithm (load-bearing):**

1. Let `cap = max(2, cap)`. If `frames.count <= cap`, return `(frames, [])` unchanged.
2. Let `duration = max(last.time − first.time, 0.001)`. For interior index `i`, with `p = i−1` and `n = i+1`:
   `cost(i) = D(p,i) + D(i,n) − D(p,n) + bonus(i) + timeGapWeight × (t_n − t_p) / duration`,
   where `D` is `difference(...).fraction`.
3. `bonus(frame)` is the maximum over both of these (0 if neither applies):
   - **by reason:** `.click` → `bonusClick`, `.commit` → `bonusCommit`, `.switchApp` → `bonusSwitch`, `.scroll` → `bonusScroll`;
   - **by action:** any `.clicked` → `bonusClick`, any `.pressedReturn` / `.pressedEscape` / `.pressedShortcut` → `bonusCommit`, any `.switched` → `bonusSwitch`, any `.scrolled` → `bonusScroll`.
4. Cache the cost of every interior frame. Each iteration:
   - Pick the minimum cost. On ties, take the lowest position (the earliest frame).
   - Append its actions to the previous frame, and remove it.
   - Recompute the cost of the **two new neighbors only**. The left neighbor's bonus may have changed because of the merged actions.
   - Never recompute everything in each iteration. With up to 300 frames, that would be far too slow.

**Low-bar reasons:** `click`, `commit`, `switchApp`, `typing`.

**Algorithm (load-bearing):**

`ingest(frame)`:
1. If finished, return `[]`.
2. `change = tracker.observe(frame, previous: latest, countTowardBusy: scroll == nil)`. If `change.motion`, set `lastMotion = frame.time`. Set `latest = frame`.
3. If `kept` is empty:
   - `out = keep(frame, .start)`
   - move `buffered` into `kept[0].actions`
   - return `out`
4. If `pending == nil && stopAt == nil`, run `evaluateVisualTrigger(now: frame.time)`.
5. Return `[]`.

`evaluateVisualTrigger(now)`:
- Proceed only if `latest.index != kept.last.frameIndex`.
- Let `d = tracker.difference(kept.last.sample, latest)`.
- If `d.fraction ≥ visualTriggerFraction`, or (`d.fraction ≥ keepFraction` and `now − kept.last.time ≥ quietKeepInterval`), set `pending = (.visual, now)`.

`ingest(event)`: if finished, return `[]`. Otherwise, with `t = event.time`:

| Event | Handling |
|---|---|
| `mouseDown` | End the typing and scroll runs (set both to nil). `attach(.clicked(...))`. |
| `mouseUp` | `setPending(.click, t)` |
| `keyTyped(field)` | End the scroll run. If `typing` is nil or its field differs, `attach(.typed(field))`. Then `typing = (field, t)`. |
| `keyReturn` / `keyEscape` / `shortcut(s)` | End the typing and scroll runs. `attach(.pressedReturn` / `.pressedEscape` / `.pressedShortcut(s))`, then `setPending(.commit, t)`. |
| `scroll(f)` | End the typing run. See **Scroll handling** below. |
| `switched(ctx)` | End both runs. `attach(.switched(to: ctx))`, then `context = ctx`, then `setPending(.switchApp, t)`. |
| `titleChanged(w)` | `context.window = w`. No action and no pending. |

**Scroll handling** for `scroll(f)`:
1. If there's no scroll run: `attach(.scrolled)`, then `scroll = (0, t)`.
2. Add `|f|` to the run's accumulated amount and set its `last = t`.
3. If accumulated ≥ `scrollKeepFraction`:
   - Reset accumulated to 0.
   - If `latest.index != kept.last.frameIndex` and `difference(kept.last, latest).fraction ≥ keepFraction`, append the outputs of `keep(latest, .scroll)`.

`attach(action, t)`:
- **No frame yet:** if there is no `latest` or no kept frame, append the action to `buffered` and return `[]`.
- **Screen unchanged:** if `latest.index == kept.last.frameIndex`, or `difference(kept.last, latest).fraction < keepFraction`, add the action to `kept.last` and return `[]`.
  - Double-click merge: if the action is a `.clicked` with `clickCount ≥ 2`, the last action on that frame is a `.clicked` with the same button, and the two points are within `doubleClickRadius`, **replace** that last action instead of appending.
- **Screen changed:**
  - `out = keep(latest, .beforeAction)`
  - append the action to `kept.last`
  - `pending = nil`
  - return `out`

`setPending(reason, t)`:
- If a pending trigger exists, set `pending = (stronger of the two reasons, t)`.
- Otherwise set `pending = (reason, t)`.

`meetsBar(frame, reason)`:
- `d = tracker.difference(kept.last.sample, frame)`.
- Return true if `d.fraction ≥ keepFraction`.
- Otherwise return true only if `reason` is low-bar and `d.changedTiles ≥ minChangedTilesAfterInput`.

`tick(now)`: if finished, return `[]`. Otherwise `tracker.advance(to: now)`, then run these steps in order:
1. **Typing pause.** If a typing run exists and `now − lastKey ≥ typingPause`: `typing = nil`, then `setPending(.typing, now)`.
2. **Scroll end.** If a scroll run exists and `now − last ≥ scrollEndDelay`: `scroll = nil`, then `setPending(.scroll, now)`.
3. **Visual trigger.** If `pending == nil && stopAt == nil`, run `evaluateVisualTrigger(now)`. This catches small changes on a static screen that sends no new frames.
4. **Settle.**
   - Proceed only if a pending trigger `p` and a `latest` frame both exist.
   - Let `quiet = now − max(lastMotion, p.since)`.
   - If `quiet ≥ settleQuiet` or `now − p.since ≥ settleTimeout`:
     - If `latest.index != kept.last.frameIndex` and `meetsBar(latest, p.reason)`, append `keep(latest, p.reason)`.
     - Set `pending = nil`.
5. **Stop.**
   - Proceed only if `stopAt` is set.
   - Let `quiet = now − max(lastMotion, stopAt)`.
   - If `quiet ≥ settleQuiet` or `now − stopAt ≥ stopSettleTimeout`:
     - If `latest` exists, `latest.index != kept.last.frameIndex`, and `meetsBar(latest, pending?.reason ?? .stop)`, append `keep(latest, .stop)`.
     - Set `pending = nil` and `finished = true`.

`stop(at t)`:
1. If `stopAt` is already set, return.
2. Set `stopAt = t` and `stopTime = t`.
3. If a typing run exists: `typing = nil`, then `setPending(.typing, t)`.
4. If a scroll run exists: `scroll = nil`, then `setPending(.scroll, t)`.
5. If `kept` is empty, set `finished = true`.

`keep(frame, reason)`:
1. Append `KeptFrame(sample: frame, context: context, actions: [], reason: reason)` and increment `candidateCount`.
2. Set `out = [.persist(frameIndex: frame.index)]`.
3. If `kept.count > candidatePoolLimit`:
   - Run `CapFitter.fit(kept, cap: candidatePoolTrimTo, …, difference: settledDifference)`.
   - Replace `kept` with the fitted list.
   - Append `.discard(frameIndices: removed)` to `out`.
4. Return `out`.

`result()`:
- Run `CapFitter.fit(kept, cap: min(max(config.maxFrames, 2), 50), …, difference: settledDifference)`.
- Return `PickResult(frames: fitted.map(PickedFrame.init), candidateCount: candidateCount, duration: stopTime)`.

```swift
    public mutating func tick(now: TimeInterval) -> [GestureEvent]         // call every ≤ 50 ms
    public mutating func reset()                                          // the recording ended elsewhere (auto-stop, menu, error)
}
```

The Input layer (M2) uses the returned events like this:
- `.cancel` returned for an `otherKeyDown(isEscape: true)` → consume that Esc.
- `.startHold` → start capturing **silently** (no pill, no sound) and strip ⌘ from mouse events until `.stopHold`, `.discardHold` or `.cancel`.
- `.revealHold` → show the pill and play the start sound.
- `.discardHold` → the hold was really a shortcut (⌘C, ⌘V): stop capturing, delete what was captured, remove the active tap. The key that caused it passes through untouched, so the shortcut works.

**Why the reveal (M0 finding):** Fayzan's natural Right ⌘ shortcuts take 270–670 ms from ⌘ down to the letter, so a 250 ms hold threshold alone mistook 8 of 10 of them for holds. Clicks are still classified at 250 ms, so a hold-and-click at 300 ms stays a cleaned-up plain click.

**State machine (load-bearing).**

Phases:
- `idle`
- `pressed(downAt)`
- `waitForRelease`
- `tapped(upAt)`
- `hold(downAt, revealed, clicked)`
- `handsFreeDown(used, downAt, fromStart)`
- `handsFreeUp`
- `handsFreeTapped(upAt)`

`advance(to: now)` runs before every input and on every tick. It repeats until no row applies, so a single late input can emit several events in order (e.g. `.startHold` then `.revealHold`):

| Phase | Condition | Becomes | Emits |
|---|---|---|---|
| `pressed(d)` | `now − d ≥ holdThreshold` | `hold(downAt: d, revealed: false, clicked: false)` (`recording = .hold`) | `.startHold` |
| `hold(d, revealed: false, _)` | `now − d ≥ holdReveal` | same, with `revealed = true` | `.revealHold` |
| `tapped(u)` | `now − u > doubleTapWindow` | `idle` | nothing (single tap is ignored in v1) |
| `handsFreeTapped(u)` | `now − u > doubleTapWindow` | `handsFreeUp` | nothing |

Inputs, handled after advancing:

| Phase | Input | Becomes | Emits |
|---|---|---|---|
| `idle` | `triggerDown(t)` | `pressed(t)` | nothing |
| `idle` | anything else | stays | nothing |
| `pressed` | `triggerUp(t)` | `tapped(t)` | nothing |
| `pressed` | `otherKeyDown` or `mouseDown` | `waitForRelease` | nothing (it was a shortcut) |
| `waitForRelease` | `triggerUp` | `idle` | nothing |
| `waitForRelease` | anything else | stays | nothing |
| `tapped` | `triggerDown(t)` | `handsFreeDown(used: false, downAt: t, fromStart: true)`, `recording = .handsFree` | `.startHandsFree` |
| `tapped` | `otherKeyDown` or `mouseDown` | `idle` | nothing |
| `hold` | `triggerUp` | `idle`, `recording = nil` | `.stopHold` (revealed or not; the session layer applies the 0.5 s accidental-hold rule) |
| `hold` | `otherKeyDown(isEscape: true)` | `waitForRelease`, `recording = nil` | `.cancel` |
| `hold(revealed: false, clicked: false)` | `otherKeyDown(isEscape: false)` | `waitForRelease`, `recording = nil` | `.discardHold` (it was a shortcut) |
| `hold(revealed: false)` | `mouseDown` | same, with `clicked = true` | nothing |
| `hold` | any other `otherKeyDown` or `mouseDown` (revealed, or after a click) | stays | nothing |
| `handsFreeDown` | `triggerUp(t)` | if `fromStart`: `handsFreeUp`; else if `!used && t − downAt < holdThreshold`: `handsFreeTapped(t)`; else `handsFreeUp` | nothing |
| `handsFreeDown` | `otherKeyDown(isEscape: true)` | `waitForRelease`, `recording = nil` | `.cancel` |
| `handsFreeDown` | other keys, `mouseDown` | same phase with `used = true` | nothing |
| `handsFreeUp` | `triggerDown(t)` | `handsFreeDown(used: false, downAt: t, fromStart: false)` | nothing |
| `handsFreeUp` | anything else, including plain Esc | stays | nothing |
| `handsFreeTapped` | `triggerDown` | `waitForRelease`, `recording = nil` | `.stopHandsFree` |
| `handsFreeTapped` | `otherKeyDown` or `mouseDown` | `handsFreeUp` | nothing |

`reset()` sets the phase to `idle` and `recording = nil`.

**File format:**
- `session.json`: `JSONEncoder` with `[.prettyPrinted, .sortedKeys]` over a private `Codable` struct with the fields `version`, `geometry`, `initialContext`, `frames: [{index, time, dirtyRects, cursor}]`, `events` (the synthesized `Codable`), `stopTime`, and `bytesPerFrame` (`grid.count × 16`).
- `tiles.bin`: every frame's `signature.values`, concatenated in frame order.
- `read` rejects a version other than 1 with `.unsupportedVersion`. It also rejects a `tiles.bin` whose length isn't `frames.count × bytesPerFrame`, with `.corruptTiles`.

**Replay (load-bearing):**
1. Build the item list from all frames and events, sorted stably by time, with frames before events at equal times.
2. Keep an integer tick counter `k`, with tick time `Double(k) × tickInterval`.
3. Before each item, tick every time strictly less than the item's time. Then process the item.
4. After the last item, tick up to and including `stopTime`. Then call `picker.stop(at: stopTime)`, and keep ticking until `isFinished`. Fail with `preconditionFailure` if that takes more than `(stopSettleTimeout / tickInterval) + 4` ticks.
5. Log each `.persist(i)` as `.keep(frameIndex: i, reason: picker.keptFrames.last!.reason)`, read right after the call that produced it. Log `.discard` outputs as they are.

**Report format:**

```
frames {F} · events {E} · stop {timestamp(stopTime)}
{m:ss.cc}  keep     #{i}  {reason.rawValue}
{m:ss.cc}  discard  #{i} #{j} …
picked {N} of {candidateCount} candidates
{line1 for each picked frame}
```

Format the time as `String(format: "%d:%05.2f", minutes, seconds)`, e.g. `0:03.41`.
